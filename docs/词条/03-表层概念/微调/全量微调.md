## 定义

全量微调（Full Fine-tuning）是指在一个预训练模型的基础上，把它的**全部参数**都拿出来继续训练，让它适配某个具体任务或风格。一句话说清：预训练模型像一块已经学了大量通识的「毛坯」，全量微调就是连地基带装修整体重做一遍——改得最彻底，也最费资源。它是[PEFT](PEFT.md) 与 [LoRA](LoRA.md) 等「只动一小撮参数」方法的对照面。

## 原理

预训练让模型具备了通用能力，但未必贴合你的具体需求。全量微调的思路最直接：在目标任务的数据上接着跑[训练与微调](../../01-底层原理/训练与微调.md)的梯度下降，更新所有权重，直到模型在新任务上表现最好。它最大的优势是「表达力上限高」——既然能改全部参数，就能学到最彻底的变化。代价也最明显：需要海量显存（要存下全部参数的梯度和优化器状态）、训练成本高、而且容易「灾难性遗忘」预训练学到的通用能力，以及训练出的产物是完整大模型、体积巨大、难以像 LoRA 那样随手分享。

## 由来与历史

全量微调是「迁移学习」时代（2014 年起）的标准操作：先在大规模数据上预训练（如 ImageNet 上的 CNN、BERT/GPT 的语言预训练），再在你的小数据集上整体微调。它在 CV 和 NLP 里都长期是主流做法。直到 2019 年之后，模型越来越大、显存越来越不够用，[LoRA](LoRA.md) 与 [PEFT](PEFT.md) 这类参数高效方法才流行起来，把「全量 vs 高效」变成今天微调路线的基本选择题。

## 应用

对使用者来说，全量微调适合「要学一个全新、强相关的概念/风格、且手上有足够算力与数据」的重任务——社区共识是：学彻底的新物种、新材质，全量微调比 LoRA 更扎实；但普通画风、角色、轻量适配，用 LoRA 性价比更高。在图像社区，它对应的产物是「checkpoint 微调」（见[风格模型](风格模型.md)）；在 NLP 里则是 Hugging Face Transformers 的标准 `Trainer` 训练流程。
