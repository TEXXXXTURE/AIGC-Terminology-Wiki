## 定义

Anthropic 是 Claude 系列模型的创造者,以安全和对齐研究闻名。Claude Opus 5 是当前 AA 智能指数最高的模型(63.05 分),也是最贵的($5/$25)。Claude Fable 5 是带 fallback 的旗舰版(62.07 分)。Claude 4.5 Haiku 是轻量版。

## 由来与历史

2021 年由 OpenAI 前成员(Dario 和 Daniela Amodei)创立。以 Constitutional AI(宪法 AI)对齐方法闻名。Claude 系列(2023→)是 ChatGPT 的主要竞争者。2025-2026 年推出 Claude 4.5/5 系列,在智能评测中持续领先。

## 应用

Claude Opus 5 智能指数 63.05(全场最高),但价格 $5/$25、速度仅 53 tok/s。适合需要最强推理能力、不在乎成本的场景。Claude Fable 5 带 fallback 机制(62.07 分)更可靠。Anthropic 的 API 通过 claude.ai 和 AWS Bedrock 提供。
